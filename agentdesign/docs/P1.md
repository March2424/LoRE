# P1 · Reviewer 主动取证验收

2026-11-18，北京时间。Pi Reviewer 已通过真实 DeepSeek 网关调用本机 Naev 源图，完成一条有证据的修复和一条范围内无证据的人工交接。

## 工具和工作流

| Pi Reviewer 工具 | 输入与范围 |
| --- | --- |
| `search_source_graph` | `issue`、`kind`、`query`。支持源语言实体名、图关系类型、occurrence ID、原生路径和原文片段。图关系与源记录都经过授权和分支检查。 |
| `get_evidence` | `evidence_id` 为完整带版本 ID，如 `source:<occurrence-id>@1` 或输入证据中的 `ref`。打开当前候选或授权源记录，核对源版本、图快照、分支和记忆读水位。输入包已有的证据可直接确认，新证据进入换包和复审。 |
| `lookup_glossary` | `query` 为源语言术语。精确匹配冻结知识快照中批准且适用的术语，返回目标译法和当前条目是否强制使用。P4 项目规则以当前条目中的术语出现位置为证据。 |
| `search_tm` | `query` 为源语言词组。优先精确原文，其次匹配连续英文词组或中文片段。只返回当前运行读水位内的已验证译例。工作台限定为当前授权证据或本批明确选择的资源，并排除待复查、失效、跨分支和当前条目自身的译例。 |
| `get_character_note` | 空参数 `{}`。后端绑定当前说话人，查批准且在该作用域可见的角色笔记。身份不明时返回 `speaker_unresolved`。 |

Pi 发出工具请求，Python 从当前任务绑定的项目、语言方向、授权资源、图快照和知识读水位查询。五个工具共享每条一次查询、至多两条结果、非空回执最多 1,024 UTF-8 字节的预算。回执记录证据 ID、源版本和可追踪位置。记忆回执另含 `memory_ref` 及版本。

命中新证据时，Python 把获准证据加入 ContextPack，在原预算内保留适用硬规则，并用新包修复及复审。查询已在输入包中的批准术语可直接确认。复审前重新做硬检查，提交前复核证据版本和上下文哈希。未命中、范围拒绝、证据冲突或预算耗尽时生成带原因的人工复核项。模型真实用量单独记录。实现见 [Python 工具](../workbench/evidence.py)、[Pi 工具注册](../pi/reviewer.mjs) 和 [LangGraph 编排](../workbench/workflow.py)。

## 固定用例与结果

使用 P0 的本地冻结源图。[P1 清单](../configs/naev-p1.json) 为两条真实 Naev occurrence 指定独立的授权范围。命中用例将星球的独立描述留到主动查询阶段，并注入一条把地名误当工程的送审稿。原始真实草译也保留在轨迹中。“皇帝之拳星”是此用例的编辑约定。Naev 源图没有原生 `branch_id`，真实用例用明确的资源范围隔离同名条目，另在离线单元用例中构造两个明确分支，验证分支过滤及证据失效。

| 用例 | Pi 查询和结果 | 最终状态 |
| --- | --- | --- |
| 皇帝之拳 `naev_b4f6f496fb782035fac1` | 查询 `Emperor's Fist`，从同名匹配中排除 6 个越界命中，取回 `source:naev_2e54989ac7194e593066@1`，出处为 `dat/spob/emperors_fist.xml:24`。源文表明这是 C 级行星。 | 初始包没有该证据。换包后把“皇帝之拳工程”改为“皇帝之拳星”，复审通过，提交 v1。 |
| 伊尼奥斯修道院 `naev_0c16ee4efca1905b14d8` | 查询 `Inios Monastery`，4 个命中越界，工具返回 `out_of_scope` 和空证据。 | 无法确认创办者，保留中性草稿，转人工。无批准版本。 |

第一次真实运行保存在 `runs/p1-live/`。两次工具查询完成，命中项的最终审校因模型输出截断而停止，未提交。随后给 P1 最终复审使用独立提示词和 4,096 输出 token 上限，固定相同样本和查询范围复验。

复验保存在 `runs/p1-live-recheck/`，两条结果符合预期。共 10 次真实模型调用、9,437 tokens（输入 6,313，输出 3,124），端到端 39.27 秒。两个 Pi 工具回执均随原生 `function_call_output` 送回 DeepSeek。只读核对了 SQLite 里的唯一批准版本，确认修复和复审都收到新增证据，最终校验绑定新包和修订稿。另一范围的同名工程 ID 和出处没有进入模型输入。

离线 P1 两条、P0 回归四条，以及专项检查均通过。新增的三个记忆工具使用离线 Pi 回执验证了注册、调用与换包，覆盖草稿术语、未验证译文、跨分支、其他角色、晚于读水位和失效等过滤。工作台还验证了同批已批准译例经过换包复审后，作为依赖写入后续译文版本。新增三项在真实 DeepSeek 网关上的选用与回执仍待复验。[工具测试](../tests/test_reviewer_source.py) · [任务集成测试](../tests/test_task_api.py)

`get_evidence` 已通过 Pi 离线桥接验证，覆盖指定版本命中、版本不符、跨分支拒绝和已选证据复读。真实网关复验待做。
