# 工作台视觉标准 v1

前端视觉的唯一基准。FastAPI 将 [`web/design/ui.css`](../web/design/ui.css) 直接提供给 React 工作台。页面与组件样例在 [`web/design/template.html`](../web/design/template.html)，可直接用浏览器打开对照。

已确认的取向：**暖纸底、深墨左栏、33px 表格密度**。改动这三项等于重做全站。

## 三条原则

1. **纸与墨**：界面是纸，文本是主角。面板只比纸亮一档，不用纯白、不用卡片阴影造层级；分区靠 1px 暖灰规线。
2. **状态 = 色 + 词 + 点**：任何状态都必须有中文词，颜色只是辅助。表格与队列只留一个点加一个词，胶囊只出现在标题行。
3. **朱砂只用三处**：实时连接点、键盘焦点环、段落标记方块。强调色泛滥，状态色就失效。

| 项 | 值 | 用途 |

## 版式

- 段落标题＝4px 朱砂方块 + 11.5px 标签 + 1px 规线（`.section`）。
- 三栏复核：队列 268 / 对照区自适应 / 证据抽屉 340。最小可用宽度 1180，窄屏只收窄、不隐藏内容。
- 数字一律等宽（`.mono`），行号与 ID 用 9px 等宽，保证纵向对齐。
- 原文用暖色底加左侧 2px 竖线，译文用亮面加 1px 描边；两者不靠字体区分。

## 写法

- 类名：基础类加 BEM 修饰（`.btn` / `.btn--primary`，`.queue__item--active`）。
- 颜色、间距、圆角、字号只允许引用 token；十六进制只出现在 `ui.css` 的 `:root` 里。
- 新组件先补进 `template.html` 的组件索引，再进业务页面；索引里没有的组件视为未完成。
- 列宽属于页面级信息，用 `style="grid-template-columns: …"` 写在表格行上，其余样式一律回 CSS。

## 不要

- 渐变、彩色大面积底、毛玻璃、卡片投影。
- 表格里用彩色胶囊表达状态，或同一行出现两种以上状态色。
- 只靠颜色区分状态，或只靠颜色表示必填与错误。
- 用字重 700 堆层级、中文伪斜体、全大写中文。
- 给按钮加发光或立体感；一屏出现两个主按钮。

## 与实现的约定

- 按钮由 `next_actions` 推导，不按 `status` 硬编码映射。
- SSE 事件只触发查询失效，不在前端做事件溯源。
- 错误显示「中文话术 + 小字机器码」，机器码即后端返回的 `reason`（当前 135 个）。
- 模型凭据由服务端环境变量提供，界面不出现密钥输入框。
